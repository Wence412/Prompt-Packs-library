> **Move from one-off prompts to reusable production systems.**

This is a production-oriented prompt library for professionals, agencies, and creators who produce commercial-grade work with AI. **310 prompt cards** are available in the browser: 188 image templates, 30 image capability cards, eight Visual Prompts Hub cards, and 84 video generation, editing, production, and workflow templates.

Image and Video are the first published collections. Writing, Learning, Business, Research, and Code will receive dedicated pages when their reviewed starter sets are ready.

## Video prompts

The Video collection is derived from the Professional Video Editing Prompts: AI Workflow Guide and AI Video Prompt Packs. It contains 84 review-led templates for editing, generation, reference-to-video, UGC, avatar, ads, social video, motion control, product, ASMR, and script workflows. Video prompt data is maintained in site/data/video-prompts.json.

The v1.3 capability packs add **30 prompt cards** for reference-led generation, precise editing, canvas extension, text-led layouts, transparent assets, visual explainers, campaign systems, and GPT Image 2.5 workflows. See [the capability-pack guide](docs/capability-packs.md) and the [GPT Image 2.5 production guide](docs/gpt-image-2.5-production-guide.md).

## 🎓 The S.E.E.D. Framework

Every production prompt follows this proven structure:

| Element | Purpose | Example |
|---------|---------|---------|
| **S**ubject | Hero object/person/scene | Product, founder, AI character |
| **E**lements | Props, materials, visual cues | Packaging, outfit, typography |
| **E**nvironment | Setting/context | Studio, lifestyle, retail shelf |
| **D**etails | Lens, lighting, style, constraints | f/1.8, soft shadows, no text |

**Result:** Consistent, repeatable, commercially-ready visuals.

📖 [Read full S.E.E.D. guide](seed-framework.md)

## 🔧 How to Use (5 Ways)

### **1. Direct Copy-Paste**
Open [`combined-prompt-library.md`](combined-prompt-library.md) → Copy prompt → Replace variables → Generate

### **2. JSON Import**
```bash
# Import into Notion, Airtable, or custom database
Use: [`prompts.json`](prompts.json) or [`chatgpt-image-prompt-library.import.json`](chatgpt-image-prompt-library.import.json)
```

### **3. CSV Spreadsheet**
```bash
# Open in Excel, Google Sheets, or prompt manager
Use: [`prompts.csv`](prompts.csv)
```

### **4. CLI/Automation**
```bash
# Parse JSON for scripting
cat prompts.json | jq '.prompts[] | select(.phase=="Phase 2")'
```

### **5. Custom Tools**
All data is structured and documented—integrate into your workflow, plugin, or app.

### **6. Searchable Browser**
The dependency-free prompt browser lives in [`site/`](site/). To preview it locally:

```bash
cd site
python3 -m http.server 8000
```

GitHub Pages is deployed through the repository's `deploy-pages.yml` workflow, which publishes the `/site` folder. The browser reads the current prompt data from this repository's public raw files.
